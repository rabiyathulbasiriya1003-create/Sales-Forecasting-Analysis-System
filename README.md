# Sales Forecasting Analysis System

## Overview

The Sales Forecasting Analysis System is a Python-based data analysis project that helps analyze sales data and generate useful business insights.
It performs Exploratory Data Analysis (EDA) on sales datasets using visualizations and statistical analysis.

## Dataset

* **Source:** Kaggle
* **Dataset:** Sales Forecasting Dataset

## Features

* Data cleaning and preprocessing
* Daily & monthly sales analysis
* Region-wise sales visualization
* Top-selling products analysis
* Sales distribution & outlier detection
* Correlation heatmap
  
## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
